# HACS Energy Monitoring Integrations for Brazil

## Recommended HACS Integrations:

### 1. Home Assistant Glow
- Repository: gtdiehl/Home-Assistant-Glow
- Description: Monitor energy consumption via LED pulses
- Perfect for Brazilian electricity meters

### 2. Tuya Local
- Repository: localTuya
- Description: Local control of Tuya devices
- Great for Brazilian smart plugs and switches

### 3. Shelly Integration
- Repository: bieniu/ha-shelly
- Description: Shelly devices integration
- Compatible with Brazilian voltage (127V/220V)

### 4. Sonoff Integration
- Repository: AlexxIT/SonoffLAN
- Description: Sonoff devices integration
- Popular in Brazil, works with local voltage

## Installation Instructions:
1. Go to HACS → Integrations
2. Search for the integration name
3. Click Download
4. Restart Home Assistant
5. Go to Settings → Integrations → Add Integration
6. Search for the integration and configure

## Brazilian-Specific Considerations:
- Voltage: 127V or 220V (check your region)
- Frequency: 60Hz
- Smart meter compatibility varies by provider
- Consider local regulations for energy monitoring
