# Clean Dashboard Application Instructions

## Step 1: Install HACS Cards (MOST IMPORTANT)

### 1.1 Go to HACS in Home Assistant
- Open Home Assistant in your browser
- Go to **HACS** in the sidebar
- Click **Frontend** tab

### 1.2 Install Mushroom Cards (MOST IMPORTANT)
- Search for **"Mushroom"**
- Click **Download** on **Mushroom Cards**
- Wait for installation to complete

### 1.3 Install Other Essential Cards
- Search for **"Button Card"** and install
- Search for **"Mini Graph Card"** and install
- Search for **"Card Mod"** and install
- Search for **"Auto Entities"** and install

### 1.4 Restart Home Assistant
- Go to **Settings** → **System** → **Restart**
- Wait for Home Assistant to restart

## Step 4: Verify Changes

### 4.1 Check Dashboard
- Go to **Overview** in Home Assistant
- You should see a clean, organized dashboard
- Devices should be grouped by room
- Modern styling should be applied

### 4.2 Troubleshooting
- If cards don't work, restart Home Assistant again
- Check that all HACS cards are properly installed
- Verify that resources are added correctly
