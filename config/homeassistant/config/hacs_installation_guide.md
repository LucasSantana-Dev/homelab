# HACS Dashboard Cards Installation Guide

## Essential Cards to Install:

### 1. Mushroom Cards
- Repository: piitaya/lovelace-mushroom
- Description: Beautiful, modern card components
- Features: Clean design, animations, responsive layout

### 2. Button Card
- Repository: custom-cards/button-card
- Description: Highly customizable button cards
- Features: Icons, colors, animations, templates

### 3. Mini Graph Card
- Repository: kalkih/mini-graph-card
- Description: Compact, beautiful graphs
- Features: Multiple entities, smooth animations, responsive

### 4. Card Mod
- Repository: thomasloven/lovelace-card-mod
- Description: CSS styling for any card
- Features: Custom styling, animations, responsive design

### 5. Auto Entities
- Repository: thomasloven/lovelace-auto-entities
- Description: Automatic entity filtering and grouping
- Features: Smart filtering, dynamic cards, responsive

## Installation Steps:
1. Go to HACS → Frontend
2. Search for each card name
3. Click Download for each card
4. Restart Home Assistant
5. Add cards to your dashboard
