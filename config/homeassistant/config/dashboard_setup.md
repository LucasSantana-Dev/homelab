# Dashboard Setup Instructions

## Step 1: Install HACS Cards
1. Go to HACS → Frontend
2. Install these cards:
   - Mushroom Cards
   - Button Card
   - Mini Graph Card
   - Card Mod
   - Auto Entities

## Step 2: Install Themes
1. Go to HACS → Frontend
2. Install these themes:
   - iOS Dark Mode
   - Material Design 3
   - Nord Theme

## Step 3: Configure Dashboard
1. Go to Settings → Dashboards
2. Create new dashboard or edit existing
3. Use the provided YAML configurations
4. Customize colors and layouts

## Step 4: Add Resources
1. Go to Settings → Dashboards → Resources
2. Add the resources from dashboard_resources.yaml
3. Apply the Brazilian theme

## Step 5: Customize
1. Adjust colors to your preference
2. Add/remove cards as needed
3. Configure entity filters
4. Set up automations

## Brazilian Features:
- Green and yellow color scheme
- Portuguese language interface
- Goiânia weather integration
- Brazilian energy monitoring
- Local service integration
